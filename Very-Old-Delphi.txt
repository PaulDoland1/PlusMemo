The source code in this distribution has been tested as far back as D2006 and will not
work with anything earlier. If you really need to use PlusMemo with something earlier,
the following will (probably) work with many older versions of Delphi, though how far
back I don't know:

Download version 7.2 from the ECM website:

https://www.ecmqc.com/Processor2/plusmemolinks.php

Probably any 32-bit version will do. I will assume you get the D2009 version.
Here is a direct link to the D2009 version:
https://www.ecmqc.com/Processor2/plusmemo.php?access=&file=PMemo7D2009.zip

Follow these steps:

1.  Delete any compiler generated files (.dcu, .bpl, .hpp, etc.) and .dproj files.
You really only need these files:
*.pas
*.inc
*.dcr
*.res
*.dpk
*.dfm

2. Rename the .dpk file to something appropriate to your version of Delphi. For example
if you are using Delphi 7, you might rename PMemo7D2009.dpk to PMemo7D7.dpk.

3. Edit the first line of your .dpk file, the package statement, to match your file name.
ex:  Package PMemo7D7

4.  I would suggest editing PMSupport.pas and replace the version of TPlusParaStrings.Add
with the 7.5 version below.

5.  Either completely comment out umBackground, or simply remember to not use it.  It is the
default, but buggy.  I suggest using umOnNeed. It works well for me.

6.  This (hopefully) should install in your version of Delphi. If not, well, we gave it a shot. 


// Version 7.5 update. Now much faster!
function TPlusParaStrings.Add(const s: { UCONVERT } string { /UCONVERT } ): Integer;
var
  splist: TParagraphsList; snewp: ParInfo;
  pmemo: TPlusMemo;
begin
  pmemo := TPlusMemo(Memo);
  pmemo.BeginUpdate;
  splist := pmemo.IParList;
  splist.fModified := True;
  Result := splist.Count;
  splist.fModStopPar := Result;

  splist.fUpdateStopPar := Result;
  snewp.ParState := [pmpOwnTextBuffer];
  snewp.ParLength := Length(s);
  if snewp.ParLength > 0 then
  begin
    snewp.ParText := StrAlloc(Length(s) + 1);
    System.Move(s[1], snewp.ParText^, SizeOf(s[1]) * snewp.ParLength);
    snewp.ParText[snewp.ParLength] := #0
  end else
    snewp.ParText := nil;
  snewp.BlockState := [];
  snewp.StartOffset := splist.fTextLen + 2;
  snewp.StartLine := splist.fVisibleLineCount;
  Inc(splist.fTextLen, snewp.ParLength + 2);
  Inc(splist.fVisibleLineCount);
  Inc(splist.fTrueLineCount);
  Inc(splist.fModLinesOffset);
  splist.Add(snewp);
  PMemo.EndUpdate;
end;
