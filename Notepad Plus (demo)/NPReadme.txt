This archive contains the Notepad Plus demo (based on TPlusMemo and its accessories)
in executable format (file Notepadp.exe) and in source code form (NPSource.zip).

The dfm that are part of the project source code were created with Delphi XE.  They
will load correctly in Delphi 5/6/7 and CBuilder 5/6.  You must have the PlusMemo v6
package installed in your design time environment in order to load these forms.
